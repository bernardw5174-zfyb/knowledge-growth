# 兼容性与验证

> 本页记录实际测试证据，不把“能打开工作区”误写成“完整兼容”。
>
> `knowledge-growth` 提供目录契约、写入生命周期和参考脚本；Agent 的联网能力、附件暴露方式、对话风格与模型能力由具体运行时决定。

## 协议的共同验收点

一项运行时测试只有在实际检查产物后，才能被记为通过：

1. 只读写当前工作区；
2. 对运行时提供本地路径的附件，使用 `scripts/import_attachment.py` 进行字节级 Raw 复制；
3. 在 `01-知识/_drafts/` 生成草稿，而不直接写入正式知识；
4. 草稿区分材料事实、暂定推断、不确定项与可逆下一步；
5. 用户明确确认后才晋升正式知识；
6. 用户要求提炼框架时，先写框架提案，确认结构后才写入 `02-框架/`；
7. 所有持久化产物不回显附件绝对路径、本机用户名或临时下载路径。

验证分两级：**双平台验证**（至少 macOS + Windows 都跑通）与**仅 macOS 验证**。不把单平台验证写成跨平台支持。

| 运行时与模型 | 已验证平台 | 已验证范围 | 已知边界 | 发布承诺 |
|---|---|---|---|---|
| **WorkBuddy + DeepSeek v4 Flash** | **macOS + Windows（双平台）** | macOS 与 Windows 均跑通：文件附件 → 字节级 Raw → Draft → 人工确认；多材料汇总、框架候选门、隐私产物检查。Windows 组合已完成干净关键回归（#P7 VALIDATED） | 早期曾出现框架直接拆分多个正式框架（候选门补入前）；已在协议层修复 | **首发正式支持路径** |
| WorkBuddy + MiniMax | macOS + Windows（随 WorkBuddy 双平台） | URL 受限时显式区分严格 Raw、二手摘录与只做草稿；框架候选提案 → 用户确认 → 正式框架 | 回复与确认轮次较多，属模型/运行时风格；可能创建运行时自身身份/记忆文件 | 随 WorkBuddy 双平台 |
| Codex + Luna | 仅 macOS | 多份材料、知识确认、框架提案 → 用户确认 → 正式框架、跨领域创建（额外跑通「社保」领域） | 微信 URL 受访问限制时只能处理用户提供的本地文件/转写；不能把转写伪装为原始网页字节 | 实验性（macOS） |
| Kimi Work + K3 | 仅 macOS | 首份 Markdown 文件：领域创建、字节级 Raw、Draft、确认晋升；协议层八项验收 7 项 PASS + 人工边界合格 | 该轮测试因 Kimi token 耗尽中断于 Day 1，未完成完整三天链路（属外部资源中断，非产品缺陷） | 实验性（macOS） |

上述记录不是对任何第三方产品的背书；它们只是本项目开发阶段的行为观察。

## 正式支持路径（v0.1 Beta）

首发正式支持路径**已完成干净回归并验证通过**：

```text
Windows + WorkBuddy + DeepSeek v4 Flash（同时 macOS 已验证）
非敏感文件附件
→ byte-identical Raw
→ Draft
→ 用户确认晋升
→ 多份 confirmed 知识的框架提案
→ 用户确认结构
→ 正式框架
```

该回归已于 2026-08-20 通过（#P7 VALIDATED），故 Windows + WorkBuddy + DeepSeek 可列为 Beta 首发正式支持路径；其余运行时按上表标注的实验性范围说明，不作跨平台或完整闭环承诺。

## URL、网页与 Raw

| 输入 | 处理原则 |
|---|---|
| Agent 获得运行时提供的本地文件路径 | 正式支持：必须使用复制脚本并校验字节一致性 |
| URL 可下载原始文件 | 可在运行时明确得到本地原始文件后按正式路径处理 |
| 登录墙、反爬、微信限制或 URL 无法取到原始文件 | 不得声称拥有字节级 Raw；请用户提供 HTML/PDF/文本文件，或明确标注为“非原始摘录” |
| WebFetch/网页转写内容 | 仅可作为显式标注的二手摘录，不能冒充原始页面副本 |

## 如何提交兼容性反馈

欢迎在 Issue 中提供已脱敏的可复现信息：

- 运行时、模型、操作系统版本；
- 输入类型（本地 Markdown / PDF / URL 等）；
- 创建的相对文件树；
- 哪些验收点通过、卡在哪里；
- 是否检查过草稿、日志或记忆文件中的本机路径泄露。

不要提交真实附件、私人地址、绝对路径、账号名、公司资料或聊天截图中的敏感内容。

## 不把差异误判为失败

以下属于模型或运行时风格，除非它导致协议产物越界，否则不计为协议失败：

- 回答长短、提问次数、选项数量；
- 标题与措辞；
- 对同一材料提出的候选结构数量；
- 是否能直接访问某个网站。

真正的失败是：改写或伪造 Raw、自动晋升、把推断写成事实、未经确认写正式框架/实践/复盘，或泄露不该持久化的本机路径信息。
