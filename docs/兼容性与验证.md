# 兼容性与验证

> 本页记录实际测试证据，不把“能打开工作区”误写成“完整兼容”。
>
> `knowledge-growth` 提供目录契约、写入生命周期和参考脚本；Agent 的联网能力、附件暴露方式、对话风格与模型能力由具体运行时决定。

## 协议的共同验收点

一项运行时测试只有在实际检查产物后，才能被记为通过：

1. 只读写当前工作区；
2. 对运行时提供本地路径的附件，使用 `scripts/import_attachment.py` 进行字节级 Raw 复制；
3. 在 `01-知识/_drafts/` 生成草稿，而不直接写入正式知识；
4. 草稿区分材料事实、暂定推断、不确定项与可逆下一步；
5. 用户明确确认后才晋升正式知识（正式页 frontmatter 带 `confirmed_at` 晋升留痕）；
6. 用户要求提炼框架时，先写框架提案，确认结构后才写入 `02-框架/`；
7. 所有持久化产物不回显附件绝对路径、本机用户名或临时下载路径；
8. 汇报前运行 `scripts/validate.py`，无 ERROR（WARN 须向用户说明）；该脚本是核心不变量的事后审计工具，不替代人工验收。

该回归已于 2026-08-20 通过（#P7 VALIDATED），故 Windows + WorkBuddy + DeepSeek 可列为 v0.1 正式支持路径；其余运行时按上表标注的实验性范围说明，不作跨平台或完整闭环承诺。

## URL、网页与 Raw

| 输入 | 处理原则 |
|---|---|
| Agent 获得运行时提供的本地文件路径 | 正式支持：必须使用复制脚本并校验字节一致性 |
| URL 可下载原始文件 | 可在运行时明确得到本地原始文件后按正式路径处理 |
| URL 可抓取正文（公开网页 / 微信文章） | 默认直接抓取正文，用 `scripts/import_url.py` 存为「非字节级」文本 Raw（抓取时间戳 + 原文 URL + 显式标注非字节级原件），**不再追问 Raw 口径**；图片 / 排版丢失在文件头如实标注 |
| 登录墙、反爬、微信限制或 URL 无法取到正文 | 不得声称拥有字节级 Raw；请用户提供 HTML/PDF/文本文件，或明确标注为"非原始摘录" |
| WebFetch/网页转写内容 | 仅可作为显式标注的二手摘录，不能冒充原始页面副本；有正文可抓时优先走 `import_url.py`，不用模型摘要充当原文 |

## 发版回归：垂直包（若有已发布垂直包）

当已有垂直包发布（见 [`docs/垂直包.md`](垂直包.md)）时，Core 每次发版**追加**以下回归，防止 Core 改动破坏包协议：

1. 将垂直包挂载到测试 vault（`_packages/<package_name>/`，git clone）；
2. 用兼容 Agent 打开测试 vault，跑一遍包的核心路径（以包内 `skills/` 与 `AGENTS.md` 为准），确认产出正确落 `vault/<领域>/`；
3. 确认 `_packages/` 只读语义生效：包内无任何写入；`git ls-files --stage | grep 160000` 为空。

> 回归结果记入本页「已有验证证据」（或包侧假设注册表）。本清单自 **v0.1.5 发版起执行**（2026-09-18 补入，对应移交项 V4）。

## 如何提交兼容性反馈

欢迎在 Issue 中提供已脱敏的可复现信息：

- 运行时、模型、操作系统版本；
- 输入类型（本地 Markdown / PDF / URL 等）；
- 创建的相对文件树；
- 哪些验收点通过、卡在哪里；
- 是否检查过草稿、日志或记忆文件中的本机路径泄露。

不要提交真实附件、私人地址、绝对路径、账号名、公司资料或聊天截图中的敏感内容。

## 不把差异误判为失败

以下属于模型或运行时风格，除非它导致协议产物越界，否则不计为协议失败：

- 回答长短、提问次数、选项数量；
- 标题与措辞；
- 对同一材料提出的候选结构数量；
- 是否能直接访问某个网站。

真正的失败是：改写或伪造 Raw、自动晋升、把推断写成事实、未经确认写正式框架/实践/复盘，或泄露不该持久化的本机路径信息。

### 关于「确认轮次较多」

确认轮次同时受**治理档位、任务不确定度与模型/运行时交互风格**共同影响：

- 批量确认能减少低风险写入的确认轮次；
- 领域不清、材料缺失、附件不可读或风险较高时，助手仍可能先追问必要信息。

不把「问题多」一律归因于模型，也不宣传切换自由模式后「AI 永远不问问题」。治理档位只调节「知识 / 框架」写入的确认摩擦，不改变「决策、实战、复盘须人显式指令」的边界。
