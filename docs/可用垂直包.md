# 可用垂直包（官方目录）

> 本目录是 Core 官方维护的垂直包清单。**Agent 回答"有哪些包可装"与解析"帮我安装 XX"时，只认本目录**，不编造目录外的包。
> 目录随 Core 发版更新；要拿最新目录，拉取最新版 Core（GitHub / Gitee 任一地址，内容一致）。

## 安装方式

- 在 Agent 里直接说"帮我安装 XX"（XX 为包名或领域，如"求职知识库"）→ Agent 按下表匹配并执行 `scripts/install_package.py`；
- 或手动运行：`python3 scripts/install_package.py <安装地址>`（clone 到 `_packages/` + 建领域工作区 + 注册 `active_domains`）。

## 目录

| 包名 | 领域 | 一句话说明 | 安装地址（国内优先 Gitee） | 最新版本 |
|---|---|---|---|---|
| job-search-bw | 求职 | 国内求职方法包：改简历 → 投简历 → 打招呼（6 份框架 + 4 个 skill，方法状态公开可核） | `https://gitee.com/BernardW/job-search-bw.git`（GitHub 备用：`https://github.com/bernardw5174-zfyb/job-search-bw.git`） | v0.1.1 |

## 包名 → 领域对照

- 匹配顺序：先按包名精确匹配，再按领域匹配（如"求职知识库"→ 领域"求职" → 包 job-search-bw）。
- 匹配不到时：如实告知"目录里没有这个包"，并建议到 Core 仓库提 issue（说明想要的领域）。
