知识生长 · 起步教程（离线版）

第一次用，从这里开始。一屏一个动作，每一步做完再走下一步。

本教程与 GitHub 仓库 README 同源；改动以 GitHub 为准，PDF 为派生。

第一次用，从这里开始

核心判断：普通人搭第二大脑，第一步不是看懂原理，而是今晚就跑通一遍——电脑 + 一个助手 + 一份不敏感的材料。

我是一个普通人。上一篇讲了「为什么从问题开始」，这篇不聊原理，只聊你怎么从零跑通第一遍。每一步做完再走下一步，全程不用懂任何技术。卡住了，翻到文末的「常见卡点」。

⚠️ 注意：当前完整体验以 Windows 电脑 + WorkBuddy 桌面端为准。手机端暂时不承诺完整的本地流程——先说清楚，免得你走到一半才发现跑不动。

第 1 步 · 准备一样东西

  • 一台 Windows 电脑。

材料不用自己找——「知识生长」起步包里自带一份「示例材料.md」（动迁主题），第一次就用它跑通。

想拿自己的材料练手？可以，准备一份不敏感的文件：Word、PDF、Markdown 都行。

⛔ 隐私提醒：不要用身份证、病历、合同、公司机密或他人隐私来做第一次测试。

✅ 完成标志：电脑能用，能上网。

第 2 步 · 安装 WorkBuddy 桌面端

知识生长不只支持一个助手——Kimi Work、Codex、Hermes 等也都能跑通；这篇以目前普及度相对较高的 WorkBuddy 为例，换成其他助手，步骤大同小异。当前完整体验仍以 WorkBuddy 为准。

从官网安装：https://www.workbuddy.cn/

请走官方入口，不要用第三方下载站。

✅ 完成标志：桌面上能打开 WorkBuddy。

第 3 步 · 下载「知识生长」起步包

任选一个能打开的地址，下载 ZIP 并解压：

  • GitHub：https://github.com/bernardw5174-zfyb/knowledge-growth
  • Gitee（国内更快）：https://gitee.com/BernardW/knowledge-growth

GitHub 入口参考（界面可能略有差异，认「Download ZIP」按钮即可）：

页面上找下载入口：GitHub 点 Code → Download ZIP，Gitee 点「克隆/下载」。下载后解压，会得到一个文件夹——名字可能叫 knowledge-growth，也可能带 -main 后缀（比如 knowledge-growth-main）。两种都行，不用改名，认准里面装着 AGENTS.md、vault、scripts 这些内容的就是它。

不需要懂 Git、仓库或命令行——把 GitHub 想成一个「放文件的网页」就行，这一步只做一件事：把整个起步包下载下来。

✅ 完成标志：你手里有一个解压好的文件夹——不管叫 knowledge-growth 还是 knowledge-growth-main，里面有 AGENTS.md、vault、scripts 就行。

第 4 步 · 把文件夹设为工作区

打开 WorkBuddy，新建一个对话，把刚解压出的那个文件夹设为工作区（不管它叫 knowledge-growth 还是 knowledge-growth-main）。

✅ 完成标志：对话里能确认，工作区指向了这个文件夹。

第 5 步 · 上传文件，发第一条指令

直接拖「示例材料.md」：打开刚解压的文件夹，把里面的「示例材料.md」拖进对话框。

想用自己的材料？可以，拖第 1 步准备的那份文件也行。

拖完后，发下面这句话（整段复制，不用改）：

请按这个工作区里的规则，处理我刚上传的这份文件：把内容分成「原文事实」「AI 的推断」「还不确定的」三块，先给我一版草稿，不要替我下结论。

AI 可能回问你两件事——「归到哪个领域」就填「演示」；「你想弄清楚什么」就填你真正关心的问题（比如：家里传的动迁消息到底有没有依据）。领域和问题都只是给材料贴的标签，这次先跑通，以后都能改。

✅ 完成标志：AI 分三块给了你草稿，而不是直接甩一段总结。

第 6 步 · 看见什么算成功

成功标志是两点，不是一段漂亮的话。为什么要看这两点？因为第二大脑不是让 AI 替你总结——原始材料原样保留 → AI 给出待确认的整理 → 你拍板，这条链缺一环，它就不是你的知识库，只是 AI 的总结。

  1. AI 明确告诉你：你的原文件已经原样留了一份副本（并说清存在哪）；
  2. AI 给了你一份待确认的草稿，把「原文事实 / AI 的推断 / 不确定」分开，而不是替你定了案。

看到这两点，第一次就跑通了。目录长什么样、有哪些规则，第一天不用管。

常见卡点

卡住的地方 怎么办
ZIP 下载不动、打不开 换另一个地址（GitHub ↔ Gitee 内容一样）
助手说找不到文件夹 回到第 4 步，确认选对了解压出的那个文件夹
助手说读不到附件 把文件直接拖进对话，再发一次
发出去 AI 直接开始「总结」 把第 5 步那段话原样再发一次，重点在「先给我草稿，不要替我下结论」
AI 追问「你想弄清楚什么」 填你真正关心的问题；用「示例材料.md」的话，材料开头就写着问题，照着说就行

跑通了，下一步？

你刚刚做的，不是「学会了一个 AI 工具」，而是第一次跑通了一个最小的知识生长闭环：

问题 → 材料 → AI 整理 → 你确认。

这就是上一篇《有的放矢？现在的问题是，连靶子都没有》四步法里的前三步——剩下那一步「你确认」，是你以后每次看三栏草稿时都会做的动作，也是唯一不能交给 AI 的一步。

以后你面对的每一份新材料，都可以重复这套动作：说清问题、附一份材料、看清三栏、你确认。用熟了，你就不用再看教程了。

关于知识生长

知识生长关注的不是「又多了一个 AI 工具」，而是普通人怎样把资料、判断与复盘连成自己的认知系统。

如果某一步卡住了，欢迎留言告诉我卡在哪一步——那是最值得修的坑。
